# Wiingy Landing Page — UI Kit

A high-fidelity recreation of Wiingy's subject landing page (e.g. "Math Tutors"). This is the primary entry point for students discovering Wiingy through search.

## Sections
1. **Top Nav** — Logo, search, nav links, CTA button, user menu
2. **Hero** — Subject heading, search input, CTA — overlapping hero image
3. **Stats** — 6 key metrics in a 3×2 grid
4. **Tutor Cards** — 4 tutor cards in a row with image, rating, name, bio
5. **Trust Builder** — 3 trust pillars (Certified Experts, Payment Protection, No Subscription)
6. **FAQ** — Accordion with common questions
7. **Footer** — 4-column layout with links and copyright

## Components Used
- `Button` (primary, sm variants)
- `Tag` (default, for tutor badges)
- `Badge` (not shown in this view)
