# Tag

Pill-shaped label used for tutor attributes, status indicators, and category markers. Features the signature Wiingy "sheen" gradient in the default variant.

```jsx
<Tag>Student favorite</Tag>
<Tag variant="success">Super tutor</Tag>
<Tag variant="brand" size="sm">Math</Tag>
```

## Variants
- **default** — Sheen gradient with shadow (the main Wiingy tag style)
- **success** — Green tint for positive indicators
- **warning** — Amber tint for caution
- **accent** — Purple tint for highlights
- **brand** — Blue tint for subjects/categories

## Sizes
- **md** — 14px font, standard padding
- **sm** — 12px font, compact padding
