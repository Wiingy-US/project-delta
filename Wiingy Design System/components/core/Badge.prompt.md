# Badge

Small status dot or count indicator. Without children, renders as an 8px dot. With children, renders as a pill with the count or text.

```jsx
<Badge variant="brand" />          {/* Status dot */}
<Badge variant="success">3</Badge> {/* Count badge */}
```

## Variants
- **default** — Grey
- **brand** — Blue
- **success** — Green
- **warning** — Amber
- **accent** — Purple
